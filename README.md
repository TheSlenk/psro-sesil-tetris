# Tetris-99+ (PSRO/SESIL Twist)

## How to Run
*Note: Open Spiel is available on Windows as well as of 2 weeks. The following displays instructions on how to setup the python env on Windows. (**Windows compatibilites are only provided on Python v3.11+**).*



**This Env has only been tested for Python v3.11. For a smooth experiance consider running this repo's Python scripts via Python v3.11**

### Installing Dependancies (Virtual Env)
- `python -m venv <virtual-env-name>`
- `./<virtual-env-name>/Scripts/activate`
- `pip install -r requirements.txt`
### Running Scripts
- `python <python-script-path>`
### Exit Virtual Env
- `deactivate`
